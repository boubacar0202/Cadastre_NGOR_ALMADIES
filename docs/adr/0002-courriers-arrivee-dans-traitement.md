# Courriers d'arrivée dans Traitement

Choisir un agent sur un courrier d'arrivée n'ouvrait pas d'attribution : Traitement ne montrait que les dossiers du secrétariat et les courriers saisis à la main dans le formulaire d'attribution.

Un courrier d'arrivée enregistré ou modifié crée une attribution quand l'agent correspond à un seul compte validé. Tant que le courrier est à traiter, changer cet agent le réattribue. Un nom sans compte, ou un courrier déjà validé ou signé, ne crée pas de nouvelle attribution. Le départ reste attribué depuis Traitement.

Le suivi administrateur liste tous les courriers d'arrivée, du plus récent au plus ancien. Les 55 531 noms historiques ne correspondent à aucun compte : ils restent dans cette liste et ne deviennent pas des dossiers à traiter. Les attributions nouvelles restent en tête de la liste en cours.
